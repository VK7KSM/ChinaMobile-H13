# ChinaMobile-H13

中国移动「和对讲」专业版 H13（同硬件平台：泉盛 MAX 11）的设备研究资料。

本仓库保存对**自有设备**的离线分析成果：模块 MCU 固件、反汇编、分析脚本、
MCU 模拟器，以及历次开发用的 Android 工程与文档记录。

## 目录

| 目录 | 内容 |
| --- | --- |
| `docs/` | 开发记录、历次交接、成果整理与复盘（全部中文） |
| `firmware/mcu/` | 模块 MCU 固件镜像与反汇编 |
| `firmware/sct3258_bootloaders/` | 公开 SCT3258 加载器变体 |
| `firmware/android_audio_config/` | 设备侧音频配置 XML |
| `tools/emulator/` | MCU 固件模拟器（Unicorn，纯离线） |
| `tools/firmware_analysis/` | 固件校验与分析脚本 |
| `tools/sct3258_analysis/` | SCT3258 静态分析脚本 |
| `probes/` | 各功能验证用 Android 工程与冻结 APK |

## 平台概要

- Android 8.1 / 高通 MSM8909 / 240×320，公网 PoC 与 DMR 专网三合一
- 专网部分：独立 MCU（Cortex-M0 类，STM32F0 外设图）经 HPI 控制 SCT3258 基带
- Android 侧通过 `/dev/ttyHS0` 与 MCU 文本协议通信，波特率 57600
- 当前模块固件版本 `0.3.66`
