# 2026-09-20 接收守望采集

由 H13 自身判定对端发射的起止（`AT+DMOGETDIGITALRXINFO`，空闲回
`0,0,0`），并在信号存在期间反复读取录音存储。录音存储是小环形缓冲，
只保留最近约一秒，因此必须边收边读；多次快照按 27 字节单元的最大重叠
拼接成完整时间轴，工具见 `tools/offline/stitch_tape.py`。

| 文件 | 内容 |
|---|---|
| `rx_tape_17units.bin` | 单次读取的末尾 1.02 秒，操作者确认内容为 "one two" |
| `rx_stitched_312units_18.7s.bin` | 14 次快照拼接，312 个 27 字节单元 |
| `rx_stitched_312units_18.7s.wav` | 上者解码音频，937 帧、纠错 c0 均值 0 |

信道：433.550 MHz、色码 8、时隙一、TG 99、**加密关闭**。
对端主叫 ID 1701。

**用途**：内容已知、解码干净的空口表示基准。**边界**：这是接收方向的
表示，与模块经 HPI 交换的表示不是一回事，详见 H13_new.md 2.8.77。
