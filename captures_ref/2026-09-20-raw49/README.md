# 剥信道编码的回归锚点（2026-09-20 首次成功发射所用素材）

| 文件 | 内容 | SHA-256 前缀 |
|---|---|---|
| `asset_air_input.bin` | **输入**：2026-08-06 从真实 DMR 发射中捕获的 68 个 27 字节 CHAN_D 单元，空口表示（含信道编码与交织） | `c3c688aaf757e6de` |
| `asset_raw49.bin` | **输出**：每帧 49 位 AMBE 参数左对齐填入 9 字节、余 23 位置零 | `eac18a5a64e2b52e` |

`asset_raw49.bin` 就是 2.8.83 那次发射真正送给模块的载荷——对端第一次
听清了内容。因此这一对文件是**唯一一个有空口结果背书的转换样本**。

`tools/offline/chan_d_to_params.py` 从输入能逐字节还原输出，
`tools/offline/check_param_packing.py` 在离线自检里核对这一点。

判据不止哈希：输出的每个 9 字节帧低 23 位必须为零（204/204 实测成立），
这是「49 位左对齐」这一说法本身的可验证形式。
