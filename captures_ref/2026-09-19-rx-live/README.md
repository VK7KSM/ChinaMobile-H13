# 2026-09-19 实时接收参照

用已验收的长流采集路径（设备上 v3.94 的 `chan_d_long_stream` 模式，
采集前会下发 `AT+DMOSETRECORDSW` 开启录音并跨块连续读）从用户 TYT 的
一次约 17 秒发射中取得，操作者已听感确认为**清晰可辨的人声**。

| 文件 | 内容 |
|---|---|
| `h13_chan_d_stream_244units.bin` | 244 个 27 字节 CHAN_D 单元，14.64 秒 |
| `decoded_14.6s.wav` | 经 `tools/chan_d_to_wav.c` 解码的 8 kHz 单声道音频 |
| `replay_segment_132units.bin` | 其中能量最高的 132 个单元，7.92 秒，用于发射重放 |

信道：433.550 MHz、色码 8、时隙一、TG 99。

**用途与边界**：这是接收方向的已知正确参照。经 2026-09-19 的两次重放发射
证明，它**不能**直接用来隔离发射侧的编码器变量——接收方向交出来的单元
与发射方向期望的表示不是同一种，详见 H13_new.md 2.8.40。
